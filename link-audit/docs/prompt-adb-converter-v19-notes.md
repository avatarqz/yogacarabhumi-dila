## B. 消費端缺陷兩則（不影響 j 窗正確性，但讀者看得到）

1. **`renderEmbed` 卡頭 `embedSrc` 書名錯指**：`30p279a`（瑜伽師地論第一頁）顯示「大乘掌珍論」、
   `30p576b` 顯示「taisho」（fallback）。推因：書開頭第一頁的 `<頁>` 標記排在 `<書>` 標記之前，
   向後（或向當前 VA）查書名抓到上一部。重現：`tools/probe-embed-html.ts`（輸出卡頭 HTML 原文）。
   建議：查書名時取「≤ VA 的最後一個 書 標記」應改為「VA 所屬 block 的所屬 書」，或對 書 邊界頁特判。

   與 pageHanTextOf 的 VA/PA 口徑缺陷（R3 pin `==38` 仍在紅）同家族，推測 `<頁>` SKIP tag 的

   （「窗尾截短」分類，附 `pageHanTextOf` 切片對照）。
