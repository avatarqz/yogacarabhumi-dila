## 2. 锚点语法（请按此产出）

- **锚点标签**＝`<树 t="…">` 宣告到的所有层级标签（若有 `<锚>` 也纳入）。取值优先 `n`，其次 `id`。
- **命名空间**＝层级最多那条 `t=` 的第一个标签（ybh＝`篇`）；其值优先 `id`／`n`，没有就取标题最后一个括号里的代码（如 `（T1579）`）。
- **带命名空间**（跨著作必用）：`NS#值` 或 `NS/值`，例 `T1579#kpD03-001`、`T1579/kpD03-001`。
- **裸值**：`kpD14-020`（同值跨著作时取「文件序第一笔」，不保证是你那部）。
- 命名空间给了却查不到 → 解析为 `null`，**不会**退回裸值（避免串到别的著作）。
